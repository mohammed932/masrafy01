# Product page — what each part does

Program catalog → a no-payslip product. Five tabs, one **Save changes** for all of them.

## Tabs

| Tab | What it does |
|---|---|
| **Name** | The product's English and Arabic name.<br>*Example:* Compound Owner / مالك وحدة في كومباوند |
| **Questions** | What the applicant is asked for this product. Under each ticked list question: the answers they pick from, and their classes if the list has them.<br>*Example:* "Which compound is your unit in?" → Mivida (Class AA), Al Rehab (Class C) |
| **Calculation** | How a figure is worked out from the answers.<br>*Example:* the compound's class decides the most they may borrow. |
| **Figures** | The amounts every bank selling this product starts from. A bank can type its own instead.<br>*Example:* Class AA → 6,000,000 |
| **Check and go live** | **Try it with sample answers** → **Work it out** (nothing is saved), then Status, **Go live**, Who uses it, **Sell it as a program**.<br>*Example:* Mivida → 6,000,000 → Go live → Sell it as "Compound Owner Loan". |

## Calculation tab

| Part | What it does |
|---|---|
| **Which question decides the income?** | The main question. A choice question gets a figure per answer. A number question gets a way: **A figure for each range** / **A percentage of the answer** / **A multiple of the answer** / **The answer divided by a figure**.<br>*Example:* Military grade → a figure per grade · Years in practice → a figure per range · Card limit → 20% |
| **One figure for each answer / class** *(new)* | Shown only when the question's answers are filed under classes. "Class" = one figure per class, not per answer.<br>*Example:* Compounds → one figure for Class AA, AB, A, B, C, Other — not one per compound. |
| **More options → It is a borrowing limit, not an income** *(new)* | Ticked: the figure is the most the customer may borrow, not an income. Asks the DBR the limit was worked out at.<br>*Example:* Class AA → may borrow up to 6,000,000, worked out at DBR 50. |
| **More options → Other ways to reach the figure** | Extra ways, each reading another question (**Add another way** → **How**). **Each bank picks one of them**, or **Every bank uses all of them** → **Take the lowest** / **Take the highest**.<br>*Example:* savings ÷ 36 and transfers × 0.7 → take the lowest. |
| **More options → A second column** | Splits the figures by another answer: **One column for each answer**, or **Put the answers in groups** (list questions only).<br>*Example:* years in practice, split by city: Major (Cairo, Alexandria) / Other. |
| **More options → A bonus percentage when something is true** | Adds a percentage when one answer is picked.<br>*Example:* export contract = Yes → +10%. |
| **More options → Adjust by I-Score** | Each bank sets a multiplier per I-Score range.<br>*Example:* score 750+ → 100% · 600–749 → 80%. |
| **More options → Conditions the customer must meet** | Refusal rules (**Add a condition** → **What is measured** → **Must be**). A customer who fails one is not shown the program.<br>*Example:* contract signed at least 12 months ago · paid at least 30% of the price. |

## Figures tab

| Part | What it does |
|---|---|
| **The amount each answer / class carries** | The main table: one amount per answer, class or range, with a column per group if there is a second column.<br>*Example:* 0–8 years: Major 20,000 / Other 15,000. |
| **Other ways' tables** | One table or figure per extra way.<br>*Example:* paid so far → 40% · down payment 500k–1m → 3,000,000. |
| **Debt-burden cap** | The DBR % for this product's figure. Blank = each bank's own cap.<br>*Example:* 50%. |
| **What each I-Score is worth** | The % of the figure counted per score range. Empty = the standard I-Score classes.<br>*Example:* 700–1000 → 100%. |
| **Plans by deposit** | Car products only: rate, longest / shortest term, share financed, smallest loan — by deposit.<br>*Example:* deposit 30%+ → rate 22%, up to 84 months. |
| **Condition limits** | The number each condition is checked against.<br>*Example:* 12 months · 30% · 2,000,000. |

The Figures tab follows the Calculation: change the calculation and save it before editing the figures.
