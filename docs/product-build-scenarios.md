# Product build scenarios

Name every product `TESTING …`. The figures are examples. Labels below are exactly as on screen.

## How to (once)

| Do | Steps |
|---|---|
| New question | Questions → **+ Question** → wording → answer type (**One choice** / **Number** …) → answers or limits → **Save question** |
| New product | Program catalog → **New product** → **Blank** → name → **Create and continue** |
| Add questions to it | **Questions** tab → **Add a question** → tick → **Done** |
| Finish | **Figures** tab → fill in → **Save changes** → **Check and go live** tab → **Try it with sample answers** → **Work it out** → **Go live** |

**Groups** (**Put the answers in groups**) appear only on a question whose answers come from a list
(Governorate, Which compound). A question you make yourself uses **One column for each answer**.

## The Calculation tab, label by label

| What you do | Label on screen |
|---|---|
| Pick the main question | **Which question decides the income?** → **Question** |
| How a number gives the figure | **A figure for each range** · **A percentage of the answer** · **A multiple of the answer** · **The answer divided by a figure** |
| Per answer or per class *(new)* | **One figure for each answer** · **One figure for each class** |
| Open the extras | **More options** |
| Borrowing limit *(new)* | tick **It is a borrowing limit, not an income** → **This ceiling was worked out at a DBR of** |
| Extra ways | tick **Other ways to reach the figure** → **Way 2** opens → **How** + **Which question does it read?** · for more: **Add another way** (button under the last way) |
| How banks use the ways | **How a bank uses these ways** → **Each bank picks one of them** / **Every bank uses all of them** |
| If all are used | **If a bank fills in more than one way** → **Take the lowest** / **Take the highest** |
| Second column | tick **A second column** → **Which question splits the columns?** → **One column for each answer** / **Put the answers in groups** |
| Groups | **Add a group** → **Which group is each answer in?** |
| Bonus | tick **A bonus percentage when something is true** → **Which question?** → **Earns the bonus** / **Does not** |
| Conditions | **Conditions the customer must meet** → **Add a condition** → **What is measured** → **Must be** → **What the customer is told when they do not meet it** |

In **How** (other ways) the options read: **One figure for each answer** · **One figure for each range of a number** ·
**A percentage of a number the customer states** · **A multiple of a number the customer states** ·
**A number the customer states, divided by a figure the bank states**.

In **Must be**: **At least what the bank states** · **At most what the bank states** · **Between the bank's two figures** ·
**At least a percentage of another figure** · **One of the answers the bank accepts**.

## 1. Pharmacy owner
**New questions:** Years open (Number) · Monthly sales (Number) · Own or rent (One choice: Own / Rent)
**Questions tab:** the 3 above + Governorate

**Calculation tab**
1. **Which question decides the income?** → Years open → **A figure for each range**
2. **More options** → tick **A second column** → **Which question splits the columns?** → Governorate → **Put the answers in groups** → **Add a group** ×2: Big cities, Rest → place Cairo, Alexandria, Giza in Big cities
3. Tick **Other ways to reach the figure** → in **Way 2**: **How**: **A percentage of a number the customer states** → Monthly sales → **How a bank uses these ways**: **Each bank picks one of them**

**Figures:** 0–5 → 20k / 15k · 5–10 → 30k / 20k · 10+ → 40k / 28k · sales 15%
**Try it:** 6 yrs Cairo → **30,000** · 6 yrs Aswan → **20,000**

## 8. Compound Owner (like the live one)
**New questions:** none. They already exist.
**Questions tab:** Owns a compound unit · Which compound · Kind of unit · Paid so far · Down payment · Contract price · Months since signing · Owned share %

**Calculation tab**
1. **Which question decides the income?** → Which compound → **One figure for each class**
2. **More options** → tick **It is a borrowing limit, not an income** → **This ceiling was worked out at a DBR of**: 50
3. Tick **Other ways to reach the figure** → **Way 2** opens; press **Add another way** 3 times for Ways 3–5:
   - Way 2 — **How**: **One figure for each range of a number** → Down payment
   - Way 3 — **How**: **A percentage of a number the customer states** → Paid so far
   - Way 4 — **How**: **One figure for each answer** → Kind of unit
   - Way 5 — **How**: **A percentage of a number the customer states** → Down payment
4. **How a bank uses these ways**: **Each bank picks one of them**
5. **Conditions the customer must meet** → **Add a condition** ×3:
   - Months since signing → **At least what the bank states**
   - Paid so far → **At least a percentage of another figure** → **A share of**: Contract price
   - Contract price → **At least what the bank states**

**Figures:** AA 6m · AB 5m · A 4m · B 3m · C 2m · Other 2m · conditions 12 / 30% / 2,000,000
**Try it:** Mivida, 24 months, paid 3m of 8m → **6,000,000** · Al Rehab → **2,000,000** · 6 months → **refused**

**Not possible on the screens:** the New loan / Top-up column and scaling by owned share. Use **Copy** if you need them.
