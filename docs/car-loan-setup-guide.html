Car loan setup guide

How to set up auto loans on the admin dashboard, start to end: the car list, a bank's car program priced on the pricing card, a no-payslip car product, product defaults, Loan Engine rules, and checking it all in the simulator.

Dashboard: localhost:5173 Version v37.0.0

Start here

Before you startafter pulling the branch

Run these once after pulling, in backend/, so your database has the new car list, questions and programs:

npx prisma migrate deploy
npm run seed:questionnaire      # category question, car ticks, republishes the questionnaire
npm run build
npm run seed:sheet-figures      # re-keys the seeded car programs onto the pricing card
npm run start:dev               # backend  → http://localhost:3000

Then in admin/: npm start (dashboard → http://localhost:5173). Log in as an operator.

How a car loan works now: every car customer, with or without a payslip, is first asked "Is the car new or used?". New cars are then asked gas or electric; used cars their model year. Then the category (American, European, Korean, Japanese, Chinese), the brand, the price and the down payment. Each bank's price is one card: a rate per down-payment band, plus exceptions for a category, a brand, or gas or electric cars.
New or used: the same for every car loanwhat differs, where to see it

Every car customer, payslip or not, answers "Is the car new or used?" (جديدة / مستعملة) as the first car question. Payslip customers pick one program, Car Loan (قرض سيارة); no-payslip customers pick their product's program (e.g. Car by Down Payment). The answer then changes what comes next and which banks they see.

Each bank program says what it finances: on its first step, Finances: New cars / Used cars / Both. A bank can keep one new-car program and one used-car program under the same name (e.g. ADIB, Bank NXT, Crédit Agricole on Car Loan).

Where to see it: Program catalog → Car Loan (the questions it asks, the banks selling it) · a bank's page → each car program shows Finances · Matching simulator → Car → Car Loan: answer New or Used and the next question changes.

Both: the car list

Add, rename or remove a category or a brandCar list

Worked example: add the category Indian and the brand Tata under it.

  1. Open Car list in the left menu. The first column is Category, the next Brand.
  2. Add the category: in the Category column's add box type English Indian, Arabic هندية → Add.
  3. Click Indian to select it.
  4. Add the brand: in the Brand column's add box type English Tata, Arabic تاتا → Add. It is filed under Indian.
  5. Find a brand: type Merc in the Brand column's search box → Mercedes-Benz (under European).
  6. Rename: row's edit action, e.g. change Arabic تاتا to تاتا موتورز. Programs keep working; they store the key, not the label.
  7. Remove: row's delete action. Refused while brands are filed under it or a bank's table names it, so remove Tata before Indian.
Note: a brand's category comes from where it is filed. Moving a brand to another category changes which category exceptions apply to it on every program.

Reference (payslip and no-payslip)

Pricing card referencetwo parts, open the one you need

The payslip and no-payslip steps above already list every value for their examples. Use this when you set up a different bank.

Fill the pricing cardwhat each band, column and exception does

1. Bands (rows). Each row is a down-payment band with a rate.

  1. In the first row type where the band starts and ends, e.g. 10 to 20 %, and its Rate, e.g. 20.
  2. Press Add a band. The new row starts where the last one ended. Type its end, or leave and above empty on the last row.
  3. A band includes its start and stops just before its end: 20% falls in the "20 to 50" band, not in "10 to 20".
  4. Remove a band with the bin icon. Exceptions that point at it lose that band too.

2. More figures (columns). Rate is always there. Add another column with one click:

ButtonWhat it doesUnit
+ Longest termThe longest the loan can run in that band. A longer request is cut to this.years
+ InsuranceThe car insurance the bank requires, shown to the customer.% of the price a year
+ Interest-free yearsIf the loan term fits inside these years, the whole loan is at 0%. Longer terms pay the band's rate.years
+ Oldest carCars older than this are refused. Use it on programs that finance used cars.years old

Leave a cell empty when that band has no such limit. The × on a column heading removes the column from every row and exception.

3. Exceptions. For cars a bank prices differently:

  1. Press Add an exception.
  2. Choose Category, Brand, Gas or Electric. For Category or Brand, pick the value (type to search). Gas and Electric apply only where the customer is asked the fuel (New Car).
  3. Under On, keep All bands or untick it and pick bands.
  4. Type only the figures that change. Leave the rest empty to keep the band's own.
  5. Press Done. The exception shows as one line, e.g. Brand BMW · all bands → Rate 9%. Use Edit or the bin to change or remove it.
Which wins: for each figure, a brand beats gas or electric, a fuel beats a category, and all of them beat the band's own row. The rows are the default: they price every car no exception covers, so gas is the default unless you add a Gas exception.
Not allowed: a figure of 0, a band that overlaps the next, an open-ended band that isn't the last, and two lines setting the same figure for the same car on the same band.

  2. Find HSBC Egypt · Used Car Loan in the table → click its last cell (conditions) → Add a condition.

Edit an existing car programand the older editors
  1. Open the program → Edit → Money. Change the card.
  2. Go to Review → Save changes.
  3. The program page shows Pricing by down payment: the bands as a table and the exceptions as sentences. The headline rate is the card's range.
"This program's tables are not in this card's shape…" means its tables use something the card cannot show (for example a rate by term). They are kept as they are, and the older editors are shown instead of the card.
Cases left on a program still change its price. While a card program has any, the Cases section stays on screen so you can remove them.
